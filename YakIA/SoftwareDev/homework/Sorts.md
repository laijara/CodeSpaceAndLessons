# Подробное руководство: Быстрая сортировка (Quick Sort) на C++

Быстрая сортировка (Quick Sort) — это один из самых быстрых и широко используемых алгоритмов сортировки. Он работает по принципу **«разделяй и властвуй»**. 

Ниже мы пошагово разберем логику алгоритма на примере, а затем детально проанализируем каждую строку кода.

---

## 🧠 Часть 1: Как это работает (Пошаговый пример)

Представим, что у нас есть небольшой массив: `[ 7, 2, 8, 3, 5 ]`


### Шаг 1: Выбор опорного элемента (Pivot)
Нам нужно выбрать элемент, относительно которого мы будем делить массив. В нашем коде мы берем элемент из середины. 
* Индексы массива: от 0 до 4. Середина: `(0 + 4) / 2 = 2`.
* Элемент под индексом 2 — это число **`8`**. Наш `pivot = 8`.

### Шаг 2: Разделение массива (Partitioning)
Мы ставим два указателя:
* **`i`** указывает на начало (число `7`).
* **`j`** указывает на конец (число `5`).

Мы хотим, чтобы слева от `pivot` оказались числа меньше него, а справа — больше.
1. Указатель `i` смотрит на `7`. `7 < 8`? Да. Оставляем на месте, двигаем `i` дальше.
2. Указатель `i` смотрит на `2`. `2 < 8`? Да. Двигаем `i` дальше.
3. Указатель `i` смотрит на `8`. `8 < 8`? Нет. Указатель `i` останавливается на числе `8`.
4. Теперь двигаем `j` (справа налево). Указатель `j` смотрит на `5`. `5 > 8`? Нет. Указатель `j` сразу останавливается на числе `5`.

Мы нашли два числа не на своих местах: `8` (слева) и `5` (справа). 
* **Меняем их местами.** Массив становится: `[ 7, 2, 5, 3, 8 ]`.
* Сдвигаем `i` и `j` на шаг друг навстречу другу. Теперь они перекрестились, цикл разделения закончен.

### Шаг 3: Рекурсия
Теперь наш массив условно поделен на две части относительно того места, где остановились указатели.
* Левая часть: `[ 7, 2, 5, 3 ]`
* Правая часть: `[ 8 ]`

Правая часть состоит из 1 элемента, она уже отсортирована. Для левой части мы **запускаем алгоритм заново** (Шаг 1 и 2), пока весь массив не выстроится по порядку: `[ 2, 3, 5, 7, 8 ]`.

## 💻 Часть 2: Полный код программы

```cpp
#include <iostream>
using namespace std;

void quickSort(int arr[], int low, int high) {
    if (low >= high) return; 
    
    int pivot = arr[(low + high) / 2]; 
    int i = low; 
    int j = high; 
    
    while (i <= j) { 
        while (arr[i] < pivot) i++; 
        while (arr[j] > pivot) j--; 
        
        if (i <= j) { 
            swap(arr[i], arr[j]); 
            i++; 
            j--; 
        }
    }
    
    if (low < j) quickSort(arr, low, j); 
    if (i < high) quickSort(arr, i, high); 
}

int main() {
    const int MAX = 100; 
    int arr[MAX];
    int n = 0;
    int input;
    
    cout << "Вводите числа (0 для завершения ввода):\n";
    
    while (true) {
        cin >> input;
        if (input == 0) break;    
        arr[n] = input;           
        n++;
        
        if (n >= MAX) {           
            cout << "Достигнут максимум (" << MAX << " элементов)\n";
            break;
        }
    }
    
    if (n == 0) {
        cout << "Массив пуст.\n";
        return 0;
    }
    
    cout << "Исходный массив: ";
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
    
    quickSort(arr, 0, n - 1);
    
    cout << "Отсортированный: ";
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
    
    return 0;
}
