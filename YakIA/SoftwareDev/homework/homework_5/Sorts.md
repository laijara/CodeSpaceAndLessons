# Полное руководство: Быстрая сортировка (Quick Sort) на C++

Быстрая сортировка — это один из самых быстрых и широко используемых алгоритмов сортировки в программировании. Ниже представлен полный разбор: от базовой логики до пошагового выполнения на конкретном примере.

---

## 🧠 Часть 1: Как работает быстрая сортировка?



Алгоритм строится на принципе **«разделяй и властвуй»**. Процесс состоит из трех основных шагов:

1. **Выбор опорного элемента (pivot).** Из массива выбирается один элемент (в нашем коде — тот, что лежит ровно посередине текущего отрезка).
2. **Разделение (Partitioning).** Массив перестраивается так, чтобы слева от опорного элемента оказались все числа, которые *меньше* него, а справа — все, которые *больше* или равны. 
3. **Рекурсия.** Этот же процесс повторяется отдельно для левой и правой части массива. Разделение продолжается до тех пор, пока в каждой части не останется по одному элементу (такие части уже считаются отсортированными).

## 💻 Часть 2: Исходный код программы

```cpp
#include <iostream>
using namespace std;

void quickSort(int arr[], int low, int high) {
    // Базовый случай рекурсии: если в отрезке 1 элемент или меньше, выходим
    if (low >= high) return; 
    
    int pivot = arr[(low + high) / 2]; // Выбор опорного элемента (середина)
    int i = low; 
    int j = high; 
    
    // Главный цикл разделения массива
    while (i <= j) { 
        while (arr[i] < pivot) i++; // Ищем элемент слева, который нужно перекинуть вправо
        while (arr[j] > pivot) j--; // Ищем элемент справа, который нужно перекинуть влево
        
        // Если нашли два "заблудившихся" элемента, меняем их местами
        if (i <= j) { 
            swap(arr[i], arr[j]); 
            i++; 
            j--; 
        }
    }
    
    // Рекурсивный вызов для левой и правой частей
    if (low < j) quickSort(arr, low, j); 
    if (i < high) quickSort(arr, i, high); 
}

int main() {
    const int MAX = 100; // Лимит массива
    int arr[MAX];
    int n = 0; // Счетчик реального количества чисел
    int input;
    
    cout << "Вводите числа (0 для завершения ввода):\n";
    
    // Цикл ввода данных
    while (true) {
        cin >> input;
        if (input == 0) break;    // 0 — сигнал к остановке ввода
        arr[n] = input;           // Сохраняем число
        n++;
        
        if (n >= MAX) {           // Защита от переполнения
            cout << "Достигнут максимум (" << MAX << " элементов)\n";
            break;
        }
    }
    
    if (n == 0) {
        cout << "Массив пуст.\n";
        return 0;
    }
    
    cout << "Исходный массив: ";
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
    
    // Вызов функции сортировки для всего массива (от 0 до n-1)
    quickSort(arr, 0, n - 1);
    
    cout << "Отсортированный: ";
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
    
    return 0;
}

```
## 🔍 Часть 3: Детальный разбор кода (по строкам)
### 3.1. Функция main() (Ввод данных)
 * **const int MAX = 100; int arr[MAX];** — Выделяем место под массив максимум на 100 чисел.
 * **int n = 0;** — Счетчик реального количества введенных чисел.
 * **while (true) { ... }** — Бесконечный цикл, который ждет ввода от пользователя (cin >> input;).
   * if (input == 0) break; — Если введен ноль, прерываем цикл (остановка ввода).
   * arr[n] = input; n++; — Сохраняем число и увеличиваем счетчик.
   * if (n >= MAX) break; — Защита от переполнения массива.
 * **quickSort(arr, 0, n - 1);** — Главный вызов функции. Передаем массив, индекс старта 0 и индекс конца n - 1.
### 3.2. Функция quickSort() (Сама сортировка)
Функция принимает массив и границы текущего отрезка (low и high).
 * **if (low >= high) return;** — **Базовый случай.** Если в отрезке 1 элемент или меньше, прерываем функцию (сортировать нечего).
 * **int pivot = arr[(low + high) / 2];** — Вычисляем индекс середины отрезка и берем это число в качестве опорного.
 * **int i = low; int j = high;** — Ставим указатель i на начало, а j на конец отрезка. Указатели будут двигаться навстречу друг другу.
 * **while (i <= j) { ... }** — Главный цикл разделения массива.
   * **while (arr[i] < pivot) i++;** — Левый указатель двигается вправо. Он пропускает числа, которые меньше опорного (они на своем месте).
   * **while (arr[j] > pivot) j--;** — Правый указатель двигается влево. Он пропускает числа, которые больше опорного.
 * **if (i <= j) { swap(...); i++; j--; }** — Если мы нашли два "заблудившихся" числа (слева слишком большое, справа слишком маленькое), **меняем их местами**. Затем сдвигаем указатели дальше.
 * **if (low < j) quickSort(arr, low, j);** — Рекурсивно вызываем сортировку для левой части массива (от low до j).
 * **if (i < high) quickSort(arr, i, high);** — Рекурсивно вызываем сортировку для правой части массива (от i до high).
## 👣 Часть 4: Пошаговая трассировка (на примере [7, 2, 5, 3, 8])
Исходный массив: [7, 2, 5, 3, 8] (индексы от 0 до 4)
### Вызов 1: Основной массив (от 0 до 4)
Вызов: quickSort(arr, 0, 4)
 * low = 0, high = 4
 * Индекс pivot: (0 + 4) / 2 = 2. Значение **pivot = 5**.
 * Указатели: i = 0, j = 4.
**Итерация 1:**
```text
[ 7,  2,  5,  3,  8 ]
  ^i              ^j

```
 * arr[i] (7) < pivot (5)? **Нет.** i останавливается.
 * arr[j] (8) > pivot (5)? **Да.** Сдвигаем j влево (j = 3, указывает на 3).
 * arr[j] (3) > pivot (5)? **Нет.** j останавливается.
 * Меняем местами arr[i] и arr[j].
 * **Массив стал:** [3, 2, 5, 7, 8]. Сдвигаем: i++ (стало 1), j-- (стало 2).
**Итерация 2:**
```text
[ 3,  2,  5,  7,  8 ]
      ^i  ^j

```
 * arr[i] (2) < pivot (5)? **Да.** Сдвигаем i вправо (i = 2, указывает на 5).
 * arr[i] (5) < pivot (5)? **Нет.** i останавливается.
 * arr[j] (5) > pivot (5)? **Нет.** j останавливается на 5.
 * Меняем местами arr[2] и arr[2] (без изменений).
 * Сдвигаем: i++ (стало 3), j-- (стало 1).
Указатели перекрестились (i = 3, j = 1). Цикл разделения завершен.
Текущее состояние массива: [3, 2, 5, 7, 8]
**Рекурсия:**
 * low < j (0 < 1). Вызываем quickSort(arr, 0, 1) для левой части [3, 2].
 * i < high (3 < 4). Вызываем quickSort(arr, 3, 4) для правой части [7, 8].
### Вызов 2: Левая часть (от 0 до 1)
Массив на входе: [3, 2]
Вызов: quickSort(arr, 0, 1)
 * low = 0, high = 1
 * Индекс pivot: (0 + 1) / 2 = 0. Значение **pivot = 3**.
 * Указатели: i = 0, j = 1.
**Итерация 1:**
```text
[ 3,  2,  5,  7,  8 ]
  ^i  ^j

```
 * arr[i] (3) < pivot (3)? **Нет.** i останавливается на 3.
 * arr[j] (2) > pivot (3)? **Нет.** j останавливается на 2.
 * Меняем местами 3 и 2.
 * **Массив стал:** [2, 3, 5, 7, 8]. Сдвигаем: i++ (стало 1), j-- (стало 0).
Условия для новой рекурсии (low < j и i < high) не выполняются. Левая часть отсортирована!
### Вызов 3: Правая часть (от 3 до 4)
Массив на входе: [7, 8]
Вызов: quickSort(arr, 3, 4)
 * low = 3, high = 4
 * Индекс pivot: (3 + 4) / 2 = 3. Значение **pivot = 7**.
 * Указатели: i = 3, j = 4.
**Итерация 1:**
```text
[ 2,  3,  5,  7,  8 ]
              ^i  ^j

```
 * arr[i] (7) < pivot (7)? **Нет.** i останавливается на 7.
 * arr[j] (8) > pivot (7)? **Да.** Сдвигаем j влево (j = 3, указывает на 7).
 * arr[j] (7) > pivot (7)? **Нет.** j останавливается на 7.
 * Меняем 7 и 7 местами.
 * Сдвигаем: i++ (стало 4), j-- (стало 2).
Условия для рекурсии не выполняются. Правая часть отсортирована!
### Итог
Все ветки рекурсии завершили работу. Массив полностью отсортирован: **[2, 3, 5, 7, 8]**.
